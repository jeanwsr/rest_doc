# 架构设计决定 (ADR)

架构设计决定 (ADR, Architecture Decision Record) 记录一个重要技术决定及其理由：当时面对什么问题、有哪些可选方案、为什么这样选择。每个 ADR 只记录一个决定，生效后即作为历史记录保留；被新决定取代时只更新状态，不删除内容。

ADR 的使用时机、与其他文档 (API 文档、开发者文档、增强提案) 的区别，以及撰写规范，见 [ADR 使用规范与说明](adr-rules-and-explanation)。
